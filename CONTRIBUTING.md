# Contributing to WorshipSavvy

Thanks for wanting to help! WorshipSavvy is built for churches, and it gets
better every time someone reports a real problem or shares an idea from running
an actual service.

## Ways to contribute

- **Report bugs** — open a
  [Bug report](https://github.com/darljed/project-worshipsavvy/issues/new/choose).
  The best reports come from people using it on a Sunday.
- **Request features** — open a
  [Feature request](https://github.com/darljed/project-worshipsavvy/issues/new/choose)
  describing the problem on your media team, not just the solution.
- **Help others** — answer questions in
  [Discussions](https://github.com/darljed/project-worshipsavvy/discussions).
- **Test** — try new releases on your Mac/Windows setup and report what breaks.
- **Translations** — UI translations, and Bible translations where the rights
  allow, are especially valuable.
- **Documentation** — improve setup guides and how-tos.

## Filing a good issue

Before opening one, please **search existing issues** to avoid duplicates. Then:

- Use the right template (Bug vs. Feature).
- Include your **OS** and **WorshipSavvy version** (Help → About).
- For visual bugs, attach a screenshot or a short screen recording.
- One issue per report — it keeps the discussion focused.

## Code contributions

The application source lives in a separate repository. If you'd like to work on
the code, **email hello@darl.dev first** so we can point you at the source repo
and talk through the change before you invest time. As a rule:

1. Open (or comment on) an issue describing the change first.
2. Keep pull requests focused and small where possible.
3. Match the existing code style and conventions.
4. Describe what you changed and how you tested it.

## Becoming a collaborator

We're glad to bring on regular contributors. If you've landed a few good issues
or PRs, or want to own an area (a translation, docs, a platform), reach out at
**hello@darl.dev**.

## Code of Conduct

Participation is governed by our
[Code of Conduct](CODE_OF_CONDUCT.md). Be kind — this is a project for churches.
