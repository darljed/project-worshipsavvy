# Code of Conduct

WorshipSavvy is a project built for churches and their communities. We want
participation here to reflect that — welcoming, respectful, and gracious.

## Our standards

Examples of behavior that helps everyone:

- Being kind, patient, and respectful to others
- Assuming good intent and giving constructive feedback
- Welcoming newcomers and helping them get started
- Focusing on what is best for the community and its churches

Examples of unacceptable behavior:

- Harassment, insults, or derogatory comments
- Personal or political attacks
- Publishing others' private information without permission
- Any conduct that would be inappropriate in a church community

## Scope

This Code of Conduct applies within all project spaces — issues, discussions,
pull requests — and whenever someone is representing the project.

## Enforcement

Report unacceptable behavior privately to **hello@darl.dev**. Reports will be
reviewed and handled confidentially. Maintainers may remove content, or block
contributors, that violates this Code of Conduct.
